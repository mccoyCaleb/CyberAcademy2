3.4 • Network Segmentation

Network Segmentation

Segmentation divides a large network into smaller sections so that a compromise in one area is less likely to spread to the entire environment. This is one of the most important design concepts in network defense.

ProgressIsolation and containment

Big idea

Containment reduces blast radius.

When one part of a network is compromised, segmentation helps stop the attacker from moving freely to other systems. Instead of a single large network, organizations create sections such as student, teacher, guest, admin, and server networks.

Core idea

Limit spread

If a student computer is compromised, segmentation reduces how far the attack can travel.

Subnets

IP-based separation

Subnetting divides a larger IP space into smaller ranges so different groups can be separated logically and operationally.

VLANs

Logical separation

VLANs let devices share the same physical infrastructure while being placed in separate logical networks with different rules.

Why segmentation matters

Segmentation is the practice of dividing a larger network into smaller sections. It helps control how devices can communicate with each other.

Without segmentation: a compromise can spread more easily. With segmentation: traffic and access can be restricted to specific groups or services.

A subnet is a smaller network created from a larger IP network. Subnetting allows administrators to define separate IP ranges and apply different controls to different network sections.

It is not necessary to master subnet math for AP-level understanding. The main idea is that network ranges can be divided into smaller sections.

A VLAN creates logical separation even when devices are physically connected to the same infrastructure. Different VLANs can host students, teachers, servers, and guests with different rules.

VLANs help enforce policy and reduce unauthorized communication between groups.

A DMZ, or demilitarized zone, is a network between an internal network and the internet. Public-facing servers such as web servers are often placed there.

The DMZ creates an additional buffer so a public service can be exposed without giving direct access to the internal network.

How segmentation helps defend

Sample environment

  • Student network: limited access, guest-like restrictions.
  • Teacher network: more trusted, but still isolated from admin systems.
  • Server network: contains business-critical resources and is protected by tighter controls.
  • Guest network: separated from sensitive internal systems.
  • Administrative network: restricted to authorized staff and sensitive tools.

In this design, a compromise in one segment does not automatically grant access to every other segment.

Which concept best explains why a school separates staff, students, and servers into different networks?

Correct: Segmentation reduces the blast radius by limiting how far an attacker can move after a breach.

Checklist

Remember

  • Segmentation reduces how far an attack can spread.
  • VLANs separate logical groups without changing physical wiring.
  • DMZs protect public services from direct access to internal systems.
  • Containment is a key defense strategy in network design.

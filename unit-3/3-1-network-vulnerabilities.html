3.1 • Network Vulnerabilities and Attacks

Network Vulnerabilities and Attacks

Networks allow devices to communicate, but they also create opportunities for interception, redirection, impersonation, and disruption. This section introduces the main attacks that target network communication and the security impact they can have.

Big idea

Networks create both connectivity and risk.

Every network transaction involves data moving between devices. That movement creates the opportunity for attackers to intercept, alter, impersonate, redirect, or flood traffic. Strong network defense must understand both how communication works and how attackers abuse it.

Addresses

IP and MAC

Computers use IP addresses to identify destinations and MAC addresses to identify interfaces on a local network.

Protocols

Rules of communication

Protocols such as ARP, DNS, HTTP/HTTPS, and ICMP control how devices exchange information and how attackers can manipulate those rules.

Security impact

Confidentiality, integrity, availability

Network attacks often threaten confidentiality by exposing data, integrity by modifying data, and availability by disrupting communication.

Core network attacks

ARP matches an IP address to a MAC address on a local network. Attackers can send false ARP information so the victim sends traffic to the attacker instead of the intended device.

Result: The attacker is placed in the middle of communication, creating an on-path attack that can expose or modify traffic.

Security impact: Confidentiality, integrity, and sometimes availability.

An on-path attack happens when an attacker sits between two communicating parties. The communication continues, but the attacker may observe or alter it.

The attack may be hidden because traffic appears to move normally. The key idea is that the attacker is not necessarily trying to stop the connection; they may want to capture or manipulate it.

MAC spoofing is when a device changes the MAC address it presents to the network to impersonate another device.

Attackers may try to bypass MAC-based restrictions, evade identification, or gain unauthorized access. However, MAC addresses are not strong authentication because they can be altered.

A switch keeps a MAC address table that maps devices to switch ports. A MAC flooding attack sends many fake MAC addresses to overwhelm that table.

If the table fills up, the switch may start forwarding traffic more broadly, which gives the attacker a chance to observe traffic they should not receive.

Eavesdropping is simply observing or capturing network traffic. The attacker may gather login information, messages, files, or other sensitive data.

Encryption is an important defense because even if data is captured, it is much harder to understand if it is encrypted.

DNS, credential theft, and denial of service

DNS translates human-readable names such as example.com into IP addresses. In a DNS poisoning attack, the attacker causes the victim to receive incorrect DNS results.

Instead of going to the legitimate website, the victim may be sent to a malicious site. That can lead to credential harvesting or other social-engineering traps.

Credential harvesting is the collection of usernames, passwords, or other authentication details. A fake login page is a common method.

Attackers often combine DNS poisoning and fake pages to trick a user into entering their account information.

A Denial-of-Service (DoS) attack aims to make a resource unavailable to legitimate users. A Distributed Denial-of-Service (DDoS) uses multiple devices to overwhelm the target.

These attacks mainly target availability.

A Smurf attack is a DoS attack that uses ICMP requests to a broadcast address while spoofing the victim’s source address.

Many devices respond, sending large amounts of traffic toward the victim. Remember the pattern: Smurf + ICMP + broadcast.

Wireless network attacks

Wireless communication creates new attack paths

Wireless networks are easier for an attacker to reach without a cable. This makes certain attacks more practical, including eavesdropping, evil twins, rogue access points, and jamming.

  • Evil twin: a malicious access point that looks like a legitimate wireless network.
  • Rogue access point: an unauthorized wireless access point attached to a network.
  • Jamming: interference designed to disrupt wireless communication and damage availability.

A user types a valid website name but is redirected to a fake website that is designed to gather credentials. Which attack is most likely happening?

Correct: This is a DNS poisoning event. The attacker redirects the victim to a malicious site that may collect credentials.

Checklist

Remember

  • Attackers often chain multiple techniques together.
  • On-path attacks may be invisible to the user.
  • Encryption reduces the usefulness of captured traffic.
  • Wireless environments make interception easier.

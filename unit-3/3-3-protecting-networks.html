3.3 • Protecting Networks

Protecting Networks

Defenders protect networks through policies, layered controls, and careful configuration. A secure network combines access rules, encryption, monitoring, segmentation, and operational choices that reduce attack exposure.

Big idea

Network defense is layered.

Security is rarely one setting or one tool. Organizations use multiple layers of control, including policies, network devices, authentication, encryption, monitoring, and network design choices. The goal is to reduce exposure while maintaining the services people need.

Policies

Rules and standards

Security policies determine which devices can connect, how users authenticate, what services are allowed, and which network controls must be enforced.

Router and switch

Network devices

Routers and switches should be hardened by disabling unnecessary services, using strong authentication, and restricting access to approved devices.

Wireless

Secure communication

Wireless security depends on strong authentication, strong encryption, controlled signal strength, and careful management of access points.

Network security policies and controls

A security policy establishes the rules and expected behavior for technology and users. For network security, policies can define who can connect, how remote access works, the allowed services, and required wireless protections.

Policies are important because technical controls need rules behind them to work consistently.

Organizations may require routers to use centralized authentication, disable unnecessary services, use firewalls, and avoid unnecessary local accounts.

Why disable unnecessary services? Every extra service creates another potential attack surface.

Switches can use port security, MAC filtering, authentication, and restrictions on connected devices. These controls reduce the chance that unauthorized devices can connect.

Switch security helps protect against unauthorized access and some forms of network manipulation.

A VPN allows users to create a protected connection to another network. This is common for remote users who need access to internal resources.

Policies may define who can use the VPN, how users authenticate, and what security requirements a device must meet.

With split tunneling, some traffic goes through the VPN while other traffic goes directly to the internet. Organizations often restrict this because it can create security gaps.

Company traffic may be protected, while personal or unrelated traffic bypasses the protected path.

Wireless and endpoint protection

Wireless security controls can limit authentication, encryption, signal strength, access points, and network naming. Organizations must control which devices are allowed to connect.

Wireless networks are exposed to the air, so they require careful protection.

Encryption protects wireless data by turning readable information into a form that an attacker should not easily understand. The notes identify WEP, WPS, and original WPA as weak options, while WPA3 is the strongest option discussed.

MAC filtering permits only designated MAC addresses to connect. It can help control access, but it is not perfect because MAC addresses can be spoofed.

Remember: network restrictions that rely on a single identifier are not always strong security.

Reducing unnecessary signal range lowers the area from which attackers might interact with the network. An organization may also disable beacon frames, but hidden does not mean secure. Attackers can still discover or interact with the network.

Protective design decisions

Network controls should fit the environment. A secure design reduces exposure by making attack paths harder to use.

  • Disable unnecessary services: reduces potential entry points.
  • Use encryption: protects confidentiality even if traffic is observed.
  • Restrict wireless range: reduces opportunities for random unauthorized access.
  • Control access to devices: prevents attackers from connecting to out-of-scope network infrastructure.

My notes

Checklist

Remember

  • Network protection is more than a single firewall.
  • Policies guide what controls are required.
  • Hidden wireless networks are not automatically safe.
  • Encryption and access controls reduce exposure.

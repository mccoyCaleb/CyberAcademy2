4.3 • Protecting devices

Protecting Devices

Device security is layered. Organizations use policies, anti-malware, security patches, host-based firewalls, and user controls so that a single weakness does not expose the whole system.

ProgressDefense in depth
Overview 4.1 4.2 4.3 4.4
Big idea

Security is strongest when multiple controls work together.

Policies define expected behavior, anti-malware detects malicious software, patches reduce vulnerabilities, and host-based firewalls restrict network access. Each control addresses a different risk.

Core device protection controls

An acceptable-use policy (AUP) describes how users may use school or company devices, networks, software, and internet access.

Common rules include prohibiting unauthorized software, restricting the use of personal USB drives, requiring updates, and establishing procedures for reporting suspicious activity.

An AUP is a management control. It defines expected behavior, but technical controls are still needed to enforce it.

A software-installation policy determines what software users may install. Organizations may require approval before installing applications or allow only approved software.

Limiting installation privileges reduces the risk of users accidentally adding unapproved software, malicious tools, or vulnerable applications.

Anti-malware software detects, blocks, quarantines, or removes malicious files and programs.

Detection can be:

  • Signature-based: looks for known malware patterns.
  • Behavior-based: looks for suspicious actions such as modifying many files or injecting into system processes.

Anti-malware is most effective when it is updated regularly and used alongside other protections.

Software may contain vulnerabilities that attackers exploit. Developers release security patches to repair known weaknesses.

The process is straightforward:

Vulnerability discovered → patch released → patch installed → exposure reduced

Patching is critical, but it does not guarantee that a system is free from malware or other weaknesses. Updates reduce exposure to known software flaws.

A host-based firewall filters incoming and outgoing traffic on an individual device. It can allow or deny traffic based on rules involving direction, protocol, source or destination address, and port numbers.

For example, a laptop may block SSH access from the Internet while allowing HTTPS traffic to a trusted website.

This is different from a network firewall, which operates at an external boundary. A host-based firewall protects the device itself.

Example

Layered defense on a school laptop

  • AUP: defines acceptable use and behavior.
  • Limited privileges: reduces uncontrolled system changes.
  • Anti-malware: finds malicious software.
  • Updates: reduce risk from known vulnerabilities.
  • Host firewall: blocks suspicious network traffic.
  • MFA: reduces the risk of stolen credentials.

Checklist

Remember

  • Policies define expected behavior.
  • Updates fix known vulnerabilities.
  • Anti-malware handles malicious software.
  • Firewalls filter network traffic.

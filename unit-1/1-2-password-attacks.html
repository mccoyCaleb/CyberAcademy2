1.2 • Suspicious Website Logins & Password Attacks

Password Attacks

Authentication is the process of verifying that someone is who they claim to be. A password is often the first barrier protecting an account, so it is an important security control.

ProgressSecurity controls
Overview 1.1 1.2 1.3 1.4 1.5 1.6 1.7
Big idea

Passwords defend access.

If an attacker obtains a password, they may be able to access personal information, messages, files, financial information, school accounts, and other connected services.

Authentication

Who are you?

A website may authenticate someone using something they know (password), something they have (security key or phone), or something they are (biometric trait).

Why it matters

Passwords are a barrier

Reused or weak passwords can expose one account and make other accounts vulnerable too.

Best practice

Unique + strong + protected

Use unique passwords, strong passphrases, and MFA whenever possible.

Password attack types

Brute force means trying many possible passwords until the correct one is found.

The difficulty depends on password length, password complexity, number of possible combinations, login protections, and whether the attacker can make unlimited attempts.

Systems can make brute-force attacks harder through strong passwords, rate limiting, account lockouts, MFA, and monitoring failed login attempts.

Password spraying uses a small number of commonly used passwords against many accounts instead of trying many passwords against one account.

Brute force: many password attempts against one account. Password spraying: a few common passwords against many accounts.

Credential stuffing uses stolen username/password combinations from previous data breaches. Attackers rely on people reusing passwords across multiple websites.

Example: a password stolen from Website A is tried on Website B. If the same password was reused, the second account may also be compromised.

A rainbow table is a precomputed collection used to help attackers recover passwords from certain types of password hashes.

Attackers can use precomputed information to recover weak passwords more quickly. This is one reason modern systems use techniques such as salting passwords before hashing them.

Encryption is designed so information can be decrypted back into its original form using the proper key.

Hashing is a one-way transformation. Passwords should generally be stored using appropriate password-hashing techniques rather than being stored as plain text.

Why password reuse is dangerous

Example

Imagine you use the same password for your gaming account, email, school account, and social media. If one service is breached and your password is exposed, an attacker could try those same credentials elsewhere.

What is the best practice?

Correct: Use a unique password or passphrase for each important account. A password manager can help generate and remember them.

Should you change your password often?

Changing a password can be helpful if a password has been stolen, exposed, shared, compromised, or used on a breached service. But constantly changing it for no reason is not always the most important improvement.

Think about it: What matters more than frequent changes?

  • Unique passwords
  • Strong passwords or passphrases
  • Multifactor authentication
  • Not sharing passwords
  • Changing compromised passwords promptly

Suspicious login activity

Cybersecurity is not just about creating a strong password. You should also be able to detect suspicious authentication activity, such as repeated failed login attempts, a login from an unexpected location, an unusual time, an unfamiliar device, password-reset requests you did not make, or unexpected security notifications.

My notes

Checklist

Remember

  • Attack types: brute force, password spraying, credential stuffing, rainbow tables.
  • Good password security: Unique + Strong + Protected + MFA.
  • Suspicious logins can be a clue that something is wrong.

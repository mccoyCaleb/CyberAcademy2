1.3 • Security Practices & Public Networks

Security Practices

Good cybersecurity is not one tool. It is multiple security controls working together. This connects directly to defense in depth, which is a major idea in cybersecurity.

Big idea

Good security is layered.

One security control should not be expected to protect everything. Defense in depth means using multiple controls so that one failed control does not automatically result in a complete compromise.

Public Wi‑Fi

Trust carefully

Public networks can be convenient, but connecting to a network means trusting the network to some degree.

Least privilege

Limit access

Users and systems should only get the permissions they need to do their jobs. No more.

MFA

More than one check

Even if an attacker gets a password, they may still be blocked if a second factor is required.

Defense in depth

Password ↓ Multifactor authentication ↓ Firewall ↓ Endpoint protection ↓ Access controls ↓ Monitoring and logging

Each control provides another opportunity to stop or detect an attack.

Key security practices

Public Wi‑Fi is common in coffee shops, airports, hotels, libraries, schools, and shopping centers. It can be convenient, but it also carries risk.

Potential risks include malicious or fake networks, unauthorized monitoring of traffic, exposure of sensitive information, attacks against poorly secured devices, and account compromise.

An evil twin is a fake Wi‑Fi network designed to imitate a legitimate network. A user may accidentally connect to the attacker’s network.

Before connecting, verify the network name, ask an employee for the correct network, avoid highly sensitive activities on untrusted networks, use encrypted connections, and keep your device and security software updated.

Least privilege means users and systems receive only the permissions they need for a task—and no more.

If an attacker compromises an account with administrator privileges, the attacker may have much more control. If the account has limited privileges, the potential damage can be reduced.

The security onion is an analogy for defense in depth: attackers must get through multiple layers of protection.

The security artichoke is another analogy for layered security. It suggests that many connected pieces may create paths toward more valuable information.

Multifactor authentication (MFA) requires more than one type of authentication factor. For example, password + code from your phone.

Even if an attacker obtains the password, they may still be unable to access the account.

Software can contain vulnerabilities. Patching means applying updates that fix bugs or security vulnerabilities.

Keeping software updated reduces the number of known vulnerabilities attackers can exploit.

A system should be configured with security in mind. Examples include disabling unnecessary services, removing unnecessary accounts, changing default credentials, restricting permissions, and enabling appropriate controls.

A backup is a separate copy of important data that can help recover from hardware failure, accidental deletion, malware, ransomware, or other data loss.

Scenario

A student account only needs to read its own assignments, but it has administrator permissions.

What security principle is being violated?

Correct: This violates least privilege. The account has more access than it needs, increasing the potential damage if it is compromised.
